# Local Development Setup

Get AverisOS running on your machine in 5 minutes.

## Prerequisites

- **Ruby**: 3.3.x or higher
- **Rails**: 8.0.x (API mode only)
- **PostgreSQL**: 15+
- **Redis**: 7+
- **Node.js**: 22 LTS (for frontend)
- **Git**: Any recent version

### macOS
```bash
# Using Homebrew
brew install ruby@3.3 postgresql redis node
brew services start postgresql
brew services start redis

# Set Ruby version
rbenv global 3.3.0  # if using rbenv
```

### Linux (Ubuntu/Debian)
```bash
# Install dependencies
sudo apt-get update
sudo apt-get install ruby-3.3 postgresql postgresql-contrib redis-server nodejs

# Start services
sudo systemctl start postgresql
sudo systemctl start redis-server
```

### Windows
- Use WSL2 (Windows Subsystem for Linux)
- Follow Ubuntu/Debian steps above

## Clone and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/AverisOS/averis-os.git
cd averis-os
```

### 2. Install Dependencies
```bash
# Install Ruby gems (Rails API backend)
bundle install

# Install JavaScript dependencies (React frontend)
npm install
```

### 3. Setup Database
```bash
# Create and migrate database
bundle exec rails db:create
bundle exec rails db:migrate

# (Optional) Load sample data
bundle exec rails db:seed
```

### 4. Setup Environment
```bash
# Copy environment template
cp .env.example .env

# Edit .env with your settings (optional for local dev)
# Default values work for local development

# Key variables for Rails API:
# DATABASE_URL=postgres://localhost:5432/averis-os_development
# REDIS_URL=redis://localhost:6379/0
# RAILS_ENV=development
```

### 5. Start Development Server

**Terminal 1: Rails API Backend**
```bash
# Start Rails API server (JSON-only, no views/assets)
bundle exec rails server

# Server runs on http://localhost:3000
# All responses are JSON
```

**Terminal 2: Sidekiq Background Jobs**
```bash
# Process async jobs and events
bundle exec sidekiq
```

**Terminal 3: React Frontend (Optional)**
```bash
# Start Vite dev server with hot reload
npm run dev

# Frontend runs on http://localhost:5173
```

### 6. Verify Setup
```bash
# Test API endpoint (JSON response)
curl -X GET http://localhost:3000/api/v1/health

# Should return JSON:
# {"status":"ok"}

# Open browser for frontend
open http://localhost:5173
```

## Rails API Mode

AverisOS backend runs in **Rails API mode** exclusively:

- **No HTML views** — only JSON responses
- **No asset pipeline** — CSS/JS managed by React frontend
- **Stateless** — each request is independent
- **Token-based authentication** — Bearer tokens, not cookies
- **CORS enabled** — frontend on different domain (localhost:5173 → localhost:3000)

All controller responses use JSON serializers, never template rendering:

```ruby
# ✓ Correct (Rails API)
render json: UserSerializer.new(user)

# ✗ Wrong (not API mode)
render :show  # would look for template
```

## Common Development Commands

### Rails Backend

```bash
# Start console for testing
bundle exec rails console

# Run migrations
bundle exec rails db:migrate

# Generate new migration
bundle exec rails generate migration AddStatusToArtifacts status:string

# Run tests
bundle exec rspec

# View routes
bundle exec rails routes | grep api
```

### React Frontend

```bash
# Start dev server with hot reload
npm run dev

# Run tests
npm test

# Build for production
npm run build

# Run E2E tests
npm run e2e
```

### Database

```bash
# Reset database (development only)
bundle exec rails db:drop db:create db:migrate db:seed

# Check database status
psql -c "\l"  # list databases
psql averis-os_development -c "\d"  # list tables
```

## Troubleshooting

### Port Already in Use

```bash
# Find what's using port 3000
lsof -i :3000

# Use different port
bundle exec rails server -p 3001
npm run dev -- --port 5174
```

### Database Connection Error

```bash
# Verify PostgreSQL is running
brew services list  # macOS
sudo systemctl status postgresql  # Linux

# Check DATABASE_URL
echo $DATABASE_URL

# Test connection
psql $DATABASE_URL -c "SELECT 1"
```

### Redis Connection Error

```bash
# Verify Redis is running
redis-cli ping  # should return PONG

# If not running
brew services start redis  # macOS
sudo systemctl start redis-server  # Linux
```

### API Returns HTML Instead of JSON

This means a request is hitting a view controller instead of an API controller.

**Check controller inheritance**:
```ruby
# ✓ Correct
class Api::V1::UsersController < Api::BaseController
end

# ✗ Wrong
class Api::V1::UsersController < ApplicationController
end
```

**Verify response type**:
```ruby
# ✓ Correct
render json: { data: ... }

# ✗ Wrong  
render :show  # looks for template
```

### Node Modules Issues

```bash
# Clear and reinstall
rm -rf node_modules package-lock.json
npm install
```

### Ruby Version Mismatch

```bash
# Check current version
ruby -v

# Should be 3.3.x
# If using rbenv
rbenv global 3.3.0
rbenv rehash
```

## Docker Alternative

If you prefer containerized development:

```bash
docker-compose up -d
# Starts PostgreSQL, Redis, Rails API, Sidekiq, React

docker-compose logs -f  # view logs
docker-compose down    # stop services
```

See `docker-compose.yml` for configuration.
