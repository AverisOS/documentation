# AverisOS Roadmap

An 18-month product vision spanning three phases: MVP & Validation (Phase 1), Market Fit (Phase 2), and Enterprise Scale (Phase 3).

---

## Phase 1: MVP & Validation (Months 1-6)

**Goal**: Build core traceability, validate problem-solution fit with design partners

**Timeline**: Now through Month 6 (6 months)

### Phase 1 Deliverables

#### M1-2: Foundation & Core Traceability
- **Artifact Management**
  - Create/read/update artifacts (requirements, features, code, tests, releases)
  - Rich metadata: title, description, type, owner, status, timeline
  - Archive vs. delete (preserve history)
  - Basic search and filtering
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: 100+ artifacts in design partner projects

- **Relationship Linking**
  - Manual artifact linking (UI + API)
  - Relationship types: implements, validates, depends_on, related_to, blocks
  - Bidirectional relationships (A→B shows B←A)
  - Relationship metadata (created_at, created_by, notes)
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: 50+ relationships per design partner

- **Project Management**
  - Create projects
  - Invite team members
  - Role-based access (admin, editor, viewer)
  - Project-level artifact isolation
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: 5+ design partner projects

#### M3: Impact Analysis
- **Impact Visualization**
  - "What breaks if I change this?" analysis
  - Dependency graph visualization (force-directed)
  - Impact breadth (direct + transitive dependencies)
  - Change risk scoring
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: Design partners use impact analysis in decision-making

- **Coverage Detection**
  - Find requirements without tests
  - Find requirements without code
  - Find code without tests
  - Visual gap detection dashboard
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: Teams fix 50%+ of detected gaps

#### M4-5: Design Partner Program
- **Design Partner Setup**
  - Onboard 5-10 design partners
  - Weekly 1:1s with each partner
  - Monthly all-hands (all partners + team)
  - Office hours (2x per week)
  - Feedback collection & prioritization
  - ✓ Estimated effort: 4 weeks
  - ✓ Success metric: 5-10 partners actively using system

- **Early Revenue**
  - Design partner pricing (50% discount on Professional tier)
  - Signed agreements with NDA + usage rights
  - ✓ Estimated effort: 2 weeks (legal + sales)
  - ✓ Success metric: $5k-10k MRR from design partners

#### M6: Polish & Launch
- **UI/UX Polish**
  - Refine onboarding flow
  - Improve artifact creation form
  - Optimize impact analysis visualization
  - Mobile-responsive design
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: NPS ≥ 40

- **Documentation & Support**
  - User guides & video tutorials
  - API documentation
  - Design partner support playbook
  - FAQ & troubleshooting
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: Support tickets < 2/week

- **Beta Launch (Limited)**
  - Public announcement (design partners + select audience)
  - GitHub open-source CLI
  - ✓ Estimated effort: 1 week
  - ✓ Success metric: 100+ signups

### Phase 1 Success Metrics

| Metric | Target | How We Measure |
|--------|--------|-----------------|
| Design partner satisfaction | NPS ≥ 50 | Monthly NPS survey |
| Feature adoption | ≥80% of features used | Product analytics |
| Impact analysis usage | ≥70% of teams use weekly | Event tracking |
| Design partner retention | 8+ of 10 partners | Monthly check-ins |
| Design partner MRR | $5k-10k | Revenue tracking |
| Product-market fit signal | Clear problem validation | Partner interviews |

### Phase 1 Technical Focus

- ✓ Domain-Driven Design foundation, selective four-phase operations (full Request/Verify/Validate/Command only for complex/critical operations — see [ADR-001](../decisions/adr-001-ddd.mdx))
- ✓ REST API with clean request/response
- ✓ PostgreSQL relational design, plus a closure table for graph traversal (see [ADR-011](../decisions/adr-011-graph-modeling.mdx))
- ✓ react-flow for impact/dependency visualization (see [ADR-012](../decisions/adr-012-impact-visualization.mdx))
- ✓ Basic auth (email/password)
- ✓ Manual linking (no AI)
- ✓ Event-driven architecture, synchronous/in-process for Phase 1 (see [ADR-006](../decisions/adr-006-event-dispatcher.mdx))
- ✓ Work ownership model (teams, assignment, backlogs) without sprint ceremony — see [Work Management Model](./work-management.mdx)

## Phase 2: Market Fit (Months 7-12)

**Goal**: Validate product-market fit, expand feature set, prepare for growth

**Timeline**: Month 7 through Month 12 (6 months)

### Phase 2 Deliverables

#### M7-8: AI-Powered Linking
- **AI Link Suggestions**
  - Analyze artifact relationships
  - Suggest likely links (ML model)
  - One-click accept/reject
  - ✓ Estimated effort: 4 weeks
  - ✓ Success metric: 80%+ acceptance rate on suggestions

- **Auto-Link from Commit Messages**
  - GitHub webhook integration
  - Parse commit messages for artifact references
  - Auto-create links (requirement #123 → commit abc1234)
  - Conflict detection (circular deps, invalid links)
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: 50%+ of commits linked automatically

#### M8-9: Git Integration Expansion
- **Full Git Sync**
  - Sync commits from GitHub/GitLab
  - Pull request linkage
  - Branch tracking
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: All design partner repos synced

- **Commit-to-Requirement Detection**
  - Heuristics: commit message parsing, file path analysis
  - Predict which requirements are affected
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: 60%+ accuracy

#### M9: Self-Hosted Deployment
- **Self-Hosted Option**
  - Docker deployment (single-container & cluster)
  - Helm charts for Kubernetes
  - PostgreSQL requirement documentation
  - Redis requirement documentation
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: 2+ design partners self-hosting

- **License & Legal**
  - Enterprise license agreement
  - Self-hosted pricing model ($10k/year base)
  - ✓ Estimated effort: 2 weeks (legal)

#### M10: Expanded Domains
- **Testing Domain**
  - Record test runs
  - Link tests to requirements
  - Coverage dashboards
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: Design partners link 50%+ of tests

- **CI/CD Integration (Beta)**
  - Webhook from CI/CD (GitHub Actions, GitLab CI, Jenkins)
  - Build status → requirement artifact
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: 3+ design partners using CI/CD integration

#### M11: Open Source CLI & SDKs
- **Open Source CLI**
  - GitHub CLI-style tool (averis-os CLI)
  - Create/update artifacts from command line
  - Batch operations (bulk import)
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: 100+ CLI users

- **SDKs**
  - Python SDK (data science integrations)
  - JavaScript SDK (CI/CD, scripts)
  - Ruby SDK (Rails integrations)
  - ✓ Estimated effort: 4 weeks
  - ✓ Success metric: 10+ SDK integrations in production

#### M12: Scale & Polish
- **Performance Optimization**
  - Query optimization (impact analysis)
  - Cache strategy (Redis)
  - Async job processing
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: P95 response time < 500ms

- **Accessibility & Localization**
  - WCAG 2.1 AA compliance
  - Internationalization foundation (i18n)
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: WAVE score ≥ 95

- **Marketing & Growth**
  - Content marketing (blog, guides)
  - Community building (Discord, GitHub Discussions)
  - Customer case studies
  - ✓ Estimated effort: 4 weeks
  - ✓ Success metric: 1000+ community members

### Phase 2 Success Metrics

| Metric | Target | How We Measure |
|--------|--------|-----------------|
| Product-market fit | Strong signals | NPS ≥ 60, retention ≥ 80% |
| SaaS MRR | $25k-50k | Revenue tracking |
| Self-hosted customers | 3-5 | Signed contracts |
| CLI downloads | 1000+ | Package registry stats |
| AI link accuracy | ≥80% | Evaluation dataset |
| Design partner → customer conversion | 70%+ | Sales tracking |

### Phase 2 Technical Focus

- ✓ AI/ML for link suggestions (start with heuristics, graduate to ML)
- ✓ Git integration & webhook processing
- ✓ Self-hosted deployment
- ✓ Advanced event processing (CI/CD, tests)
- ✓ Open source strategy (CLI, SDKs)
- ✓ Performance optimization
- ✓ Delivery workflow layer: sprint planning, basic Agile workflow, Kanban boards, Waterfall stage-gates — moved from Phase 1 (see [PRD: "Why the Phase Boundary Is Drawn Here"](./prd.mdx#why-the-phase-boundary-is-drawn-here))

## Phase 3: Enterprise Scale (Months 13-18+)

**Goal**: Build enterprise features, prepare for large organizations, establish market leadership

**Timeline**: Month 13 through Month 18+ (6 months+)

### Phase 3 Deliverables

#### M13-14: Enterprise Features
- **SSO & Advanced Auth**
  - OAuth2 / OpenID Connect
  - SAML support
  - LDAP integration (Active Directory)
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: 5+ enterprise customers using SSO

- **Audit & Compliance**
  - Complete audit log (who changed what when)
  - GDPR compliance (data export, right to be forgotten)
  - SOC 2 Type II compliance
  - HIPAA readiness
  - ✓ Estimated effort: 4 weeks
  - ✓ Success metric: SOC 2 certification achieved

- **Advanced Permissions**
  - Fine-grained role-based access (RBAC)
  - Custom roles
  - Permission inheritance
  - ✓ Estimated effort: 2 weeks
  - ✓ Success metric: Enterprise customers customize 50% of roles

#### M14-15: Microservices Architecture
- **Extract High-Traffic Domains**
  - Traceability service (independent scaling)
  - Git integration service (webhook processing)
  - Email service (async delivery)
  - ✓ Estimated effort: 6 weeks
  - ✓ Success metric: Latency reduced 50%, throughput increased 3x

- **Service-to-Service Communication**
  - Event streaming (Kafka or RabbitMQ)
  - Request/response patterns
  - Circuit breakers & resilience
  - ✓ Estimated effort: 4 weeks

#### M15-16: Advanced Analytics
- **Velocity Metrics**
  - Time from requirement to release
  - Feature completion rate
  - Change frequency analysis
  - ✓ Estimated effort: 3 weeks
  - ✓ Success metric: Teams make decisions based on analytics

- **Risk Scoring**
  - Circular dependency detection
  - Coverage gap scoring
  - Untested code scoring
  - ✓ Estimated effort: 2 weeks

#### M16-17: Extensibility
- **Plugin System**
  - Custom domain creation
  - Integration marketplace
  - Webhook system (publish events)
  - ✓ Estimated effort: 4 weeks
  - ✓ Success metric: 10+ third-party integrations

- **GraphQL API**
  - GraphQL endpoint
  - Powerful query language
  - Subscriptions for real-time updates
  - ✓ Estimated effort: 3 weeks

#### M17-18: Market Expansion
- **Mobile Apps**
  - iOS & Android apps
  - Native notification support
  - Offline mode (limited)
  - ✓ Estimated effort: 6 weeks
  - ✓ Success metric: 1000+ app installs

- **Premium Features**
  - Advanced AI (custom models)
  - Dedicated support
  - Custom integrations
  - ✓ Estimated effort: 4 weeks
  - ✓ Success metric: Premium tier at $10k+/month

### Phase 3 Success Metrics

| Metric | Target | How We Measure |
|--------|--------|-----------------|
| Enterprise customers | 10+ | Signed contracts |
| Enterprise MRR | $100k+ | Revenue tracking |
| SaaS + self-hosted total MRR | $150k+ | Combined revenue |
| Product maturity | Industry standard | Customer feedback |
| Developer ecosystem | Active | Community contributions |

### Phase 3 Technical Focus

- ✓ Enterprise security (SSO, SAML, audit logs)
- ✓ Microservices architecture
- ✓ Advanced analytics & ML
- ✓ GraphQL API
- ✓ Plugin/extensibility system
- ✓ Mobile apps
- ✓ IDE integration (VS Code, JetBrains) — moved from Phase 1; CLI (Phase 1) validates developer-experience demand first

## Key Assumptions

1. **Design Partner Validation**: 5-10 design partners validate problem-solution fit in Phase 1
2. **AI Feasibility**: Open-source models (Ollama, OpenRouter) sufficient for Phase 2 AI needs
3. **Git Integration Demand**: Design partners need and use GitHub/GitLab sync
4. **Self-Hosted Demand**: 3-5 customers want self-hosted by end of Phase 2
5. **Enterprise Growth**: Market supports 10+ enterprise customers by Phase 3

## Risk Mitigation

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Design partners don't find value | High | Weekly 1:1s, rapid iteration, clear feedback loops |
| AI linking not accurate enough | Medium | Start with heuristics, collect training data, refine |
| Scaling issues | Medium | Performance budgets (M12), load testing, optimization |
| Enterprise competition | High | First-mover advantage in traceability space, deep customization |
| Team retention | High | Clear vision, interesting technical challenges, equity |
